## 浏览器 QA

Browser plugin 的 browser 技能未提供（Browser plugin not available），使用项目 Playwright。页面身份正确、非空、无错误覆盖层；主路径无相关控制台 error/warn；操作按后续 DOM 状态断言。六个流程覆盖桌面主链路、手机输入/单位/删除、20 菜目录、提交后断连、版本冲突和初始失败/键盘。

真实路径：样例 → 番茄详情（Need 2 / Have 1 / Missing 1）→ 清单 → 重复生成仍为 1 → 番茄改 2 → Nothing to buy → 刷新保留 → 首页只有继续使用。

截图检查后改进了 skip-link 的屏幕外隐藏方式，避免长截图中的固定层遮挡；长篇来源调整改为可展开显示。修改后全套检查重新通过。全部生成图另用 5×4 缩略图核对，未见错配或带文字/水印；图片是示意图，不代表实测摆盘或精确份量。

截图文件由测试输出：v1-desktop-recipes.png、v1-mobile-pantry.png、v1-mobile-shopping.png、v1-recipe-detail.png；CI 的 v1-browser-evidence artifact 可保存对应运行证据。本机最终截图另留存在本次聊天可视化目录。
