1. **Primary Metric — 24h PR Merge-Evidence Completeness (PR + Reviews + Linked Issues, Bidirectional)**:
   - **Allowed evidence locations (all timestamped `<= mergedAt + 24h` and `<= 2026-11-24 15:55 UTC`)**: the PR body, PR reviews/comments, and any tracking Issue linked in **either direction** (`Refs`/`Closes #...` on the PR, or an explicit registry entry/comment on the Iteration 1 tracking hub `#9` or feature Issue `#6`/`#14`/`#16`/`#13`).

     - **(1) Linked Issue**: PR links an Issue (`Refs`/`Closes #...`) **or** is explicitly registered in the Iteration 1 tracking hub `#9` within 24h of merge.
     - **(2) Accurate Scope**: Complete scope of changed files/artifacts recorded in the PR body **or** in a PR review/comment within 24h.

Narrative inspection without executed CLI commands does **not** pass item (3).

     - **(5) Required Non-Author Approval & CI Run Link**: Required non-author `APPROVED` review plus at least one GitHub Actions CI run URL for the PR/merged head recorded within 24h.
